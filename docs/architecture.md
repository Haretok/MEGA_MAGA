# Продуктовый дизайн решения

## 1. Проблема и ценность
* **Сотрудник**: «Проходи за 1 секунду без поиска карты в сумке и без ожидания в 90-секундной очереди»[cite: 1].
* **Охрана**: «Забудь о рутинном разборе 40 забытых карт в день — разбирай только 2–3 рискованных случая в удобном интерфейсе»[cite: 1].
* **Бизнес**: «Экономия до 31+ млн ₽ в год на рабочих часах, исключение передачи карт посторонним и полный аудит доступа»[cite: 1].

## 2. Бэклог продуктовых гипотез

| Гипотеза | Ожидаемый эффект | Охват | Риск | Стоимость проверки | Приоритет |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **1. Проход по лицу вместо карты** | Экономия 90 сек в пиковой очереди | 100% сотрудников | Средний (FAR/FRR) | Низкая (PoC + Pilot) | **P0**[cite: 1] |
| **2. Ручной контроль сомнительных кейсов охраной** | Безопасность при сбоях ML/Liveness | ~2-5% проходов | Низкий | Низкая (UI охраны) | **P0**[cite: 1] |
| **3. Детект прохода «паровозиком» (Tailgating)** | Исключение прохода без регистрации | 100% проходов | Высокий (ложные) | Средняя (вторая камера) | P1 |
| **4. Гостевой доступ по предрегистрации** | Ускорение прохода гостей | ~5% потока | Средний | Средняя | P2 |
| **5. Self-service при частых FRR** | Пересъемка шаблона в мобильном приложении | ~1% сотрудников | Низкий | Высокая | P2 |

### Детализация P0 гипотез:
1. **Проход по лицу**: Если включить Face ID на 1 проходной в ассистирующем режиме, то время прохода сократится с 6 до 1 сек, а очередь уменьшится на 80%. Проверка: Shadow Pilot 2 недели на КПП-1. Метрика: p95 latency < 1s, FRR < 2%.
2. **Ручной контроль охраны**: Если отправлять low-confidence кадры на планшет охраны, то FAR снизится до 0%, а пропускная способность не упадет. Проверка: Эмуляция сомнительных кадров в пик.

## 3. Метрики продукта
* **North Star Metric**: Доля автоматических проходов (<1 сек) без единого подтвержденного False Accept (Цель: >92%)[cite: 1].
* **Guardrail Metrics**:
  * **False Accept Rate (FAR)**: <= 0.001% (При пробитии -> переключение проходной в ассистирующий режим)[cite: 1].
  * **False Reject Rate (FRR)**: <= 2.0% (При пробитии -> алерт инженерам на калибровку порогов)[cite: 1].
  * **p95 Latency**: <= 800 ms (При пробитии -> переключение на lightweight-модель)[cite: 1].

## 5. План раскатки и пилот
1. **Shadow Mode (2 недели)**: Лицо распознается, турникет открывается только по карте[cite: 1].
2. **Ассистирующий режим (2 недели)**: Лицо открывает турникет, при ошибке — прикладывание карты[cite: 1].
3. **КПП-1 Full Rollout (1 месяц)**: Полный проход по лицу на первой проходной[cite: 1].
4. **Все КПП (Кампус)**: Масштабирование на все 3 проходные[cite: 1].
