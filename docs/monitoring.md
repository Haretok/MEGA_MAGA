# Наблюдаемость и мониторинг (Monitoring)

## 1. Метрики системы
* **Технические**: Latency p50/p95/p99 (цель p95 < 800ms), FPS с камер, Uptime Edge-узлов, задержка синхронизации HNSW-кеша.
* **ML-метрики**: Доля `manual_review` кейсов, распределение match_scores, процент отказов по Quality/Liveness, дрейф условий освещения.
* **Бизнес-метрики**: Пропускная способность (чел/мин), время прохода в пик, количество вызовов охраны.

## 2. Стартовые Алерты
1. `p95_latency > 1000ms` в течение 5 минут -> Warning.
2. `edge_offline_minutes > 15` -> Critical.
3. `manual_review_rate > 10%` на конкретной камере -> Предупреждение о сбое освещения/грязи на объективе.
