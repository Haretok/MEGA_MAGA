# Наблюдаемость и мониторинг (Monitoring)

## 1. Метрики системы
* **Технические**: Latency p50/p95/p99 (цель p95 < 800ms)[cite: 1], FPS с камер, Uptime Edge-узлов, задержка синхронизации HNSW-кеша[cite: 1].
* **ML-метрики**: Доля `manual_review` кейсов[cite: 1], распределение match_scores[cite: 1], процент отказов по Quality/Liveness[cite: 1], дрейф условий освещения[cite: 1].
* **Бизнес-метрики**: Пропускная способность (чел/мин)[cite: 1], время прохода в пик[cite: 1], количество вызовов охраны[cite: 1].

## 2. Стартовые Алерты
1. `p95_latency > 1000ms` в течение 5 минут -> Warning.
2. `edge_offline_minutes > 15` -> Critical.
3. `manual_review_rate > 10%` на конкретной камере -> Предупреждение о сбое освещения/грязи на объективе.
