# Риски, Low-Latency и Безопасность

## 1. Low-latency, надёжность и деградация
* **1 секунда Target**: Edge Pipeline = Frame Decode (15ms) + Crop/Quality (30ms) + Liveness (80ms) + Embedding (100ms) + HNSW Search (10ms) + Rule Engine (5ms) = **~240ms p95**.
* **Кеширование**: Локальный HNSW-индекс на Edge. Синхронизация delta-updates каждые 5 минут.
* **Offline-режим**: При потере сети Edge принимает решения локально. Если кеш старше 120 мин, порог открытия поднимается до `0.90`.
* **Защита от двойного открытия**: Каждое открытие использует уникальный `decision_id` с программным кулдауном контроллера 3 секунды.

## 2. Privacy, safety и governance
* **Данные**: Исходные кадры **НЕ хранятся** на Edge-узлах. Хранятся только шифрованные 512D векторы.
* **Защита шаблонов**: Применяется шифрование AES-256 и солирование векторов ключом проходной.
* **Удаление биометрии**: При отзыве согласия/увольнении вектор удаляется из центральной БД и из HNSW-индекса на Edge за <60 секунд.
