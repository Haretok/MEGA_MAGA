# Риски, Low-Latency и Безопасность

## 1. Low-latency, надёжность и деградация
* **1 секунда Target**: Edge Pipeline = Frame Decode (15ms) + Crop/Quality (30ms) + Liveness (80ms) + Embedding (100ms) + HNSW Search (10ms) + Rule Engine (5ms) = **~240ms p95**[cite: 1].
* **Кеширование**: Локальный HNSW-индекс на Edge[cite: 1]. Синхронизация delta-updates каждые 5 минут[cite: 1].
* **Offline-режим**: При потере сети Edge принимает решения локально[cite: 1]. Если кеш старше 120 мин, порог открытия поднимается до `0.90`[cite: 1].
* **Защита от двойного открытия**: Каждое открытие использует уникальный `decision_id` с программным кулдауном контроллера 3 секунды[cite: 1].

## 2. Privacy, safety и governance
* **Данные**: Исходные кадры **НЕ хранятся** на Edge-узлах[cite: 1]. Хранятся только шифрованные 512D векторы[cite: 1].
* **Защита шаблонов**: Применяется шифрование AES-256 и солирование векторов ключом проходной[cite: 1].
* **Удаление биометрии**: При отзыве согласия/увольнении вектор удаляется из центральной БД и из HNSW-индекса на Edge за <60 секунд[cite: 1].
