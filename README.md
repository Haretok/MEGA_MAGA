# CV/ML Система распознавания лиц на проходной

Система контроля и управления доступом (СКУД) на основе компьютерного зрения для офисного кампуса (12 000 сотрудников, 3 проходные).

## Бизнес-ценность
Система ускоряет проход сотрудников в пиковый период (8:45–9:45) с 96 секунд (очередь + карта) до <1 секунды на человека. Экономит компании более 30 млн рублей в год за счёт исключения потерь рабочего времени в очереди и разгрузки охраны от ручной проверки забытых карт. Исключает передачу карт третьим лицам.

## Запуск PoC (Демо)
Запуск демо-скрипта:
`python main.py`

## Реализация vs Архитектурный дизайн
* **Реализовано в PoC**: FastAPI-сервер принятия решений, обработка Happy Path (`allow`), обработка рискованных сценариев (`manual_review`), логика фалбека при offline/низком качестве, генерация Audit Log (`audit_log.jsonl`).
* **Mock-компоненты**: Извлечение эмбеддингов и Liveness заменены эвристиками/моками; векторная база смоделирована в памяти.
